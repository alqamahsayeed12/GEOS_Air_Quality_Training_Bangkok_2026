# Contributing

## Participant Questions

Open an issue and include the module, cell heading, complete error message,
Python version, and whether you are using Colab or a local environment. Do not
include API keys or personal information.

## Proposed Changes

1. Fork or branch from `main`.
2. Keep scientific-method changes separate from visual or editorial changes.
3. Preserve units, UTC conventions, QA/QC thresholds, and provenance fields.
4. Run `python scripts/verify_package.py`.
5. Submit a pull request describing the behavior and validation performed.

Generated outputs and complete research archives should not be committed.
