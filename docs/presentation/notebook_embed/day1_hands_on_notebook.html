Day 1: Introduction to GEOS and First Hands-on PM2.5 Analysis¶

Technical Training on GEOS Data for Air Quality Monitoring in Lao PDR
Bangkok, 7 September 2026

This notebook supports the first day of training. It introduces GEOS PM2.5 data, opens a sample NetCDF file, visualizes PM2.5 over mainland Southeast Asia, and compares GEOS estimates with Thai PCD ground observations.

Learning Goals¶

By the end of this notebook, participants should be able to:

  • open a GEOS NetCDF file with Python;
  • inspect dimensions, coordinates, and variables;
  • calculate or read PM2.5 fields;
  • map GEOS PM2.5 over the Laos/Thailand region;
  • compare GEOS PM2.5 with ground-monitor observations;
  • interpret simple validation statistics.

2. PM2.5 Field¶

Some GEOS-derived files include a ready-made PM25 or GEOSPM25 field. If not, PM2.5 can be approximated from aerosol species. In this sample file, we calculate a training-demo PM2.5 field from available species and use zero for missing species.

In [4]:
def species_or_zero(dataset, name, template_name="DUSMASS25"):
    if name in dataset:
        return dataset[name]
    print(f"Warning: {name} is missing; using zero contribution.")
    return xr.zeros_like(dataset[template_name])


if "GEOSPM25" in ds:
    pm25 = ds["GEOSPM25"]
elif "PM25" in ds:
    pm25 = ds["PM25"]
else:
    pm25 = (
        species_or_zero(ds, "DUSMASS25")
        + species_or_zero(ds, "SSSMASS25")
        + species_or_zero(ds, "BCSMASS")
        + species_or_zero(ds, "OCSMASS")
        + species_or_zero(ds, "SO4SMASS")
        + species_or_zero(ds, "NISMASS25")
    )

pm25.name = "PM25_demo"

5. Validation Metrics¶

These metrics are useful for first-pass model evaluation:

  • Mean bias: average model minus observation.
  • RMSE: typical error magnitude.
  • Correlation r: timing/co-variability.
  • IOA: index of agreement, where values closer to 1 indicate better agreement.
In [8]:
def metrics(obs, pred):
    obs = np.asarray(obs, dtype=float)
    pred = np.asarray(pred, dtype=float)
    mask = np.isfinite(obs) & np.isfinite(pred)
    obs = obs[mask]
    pred = pred[mask]
    n = len(obs)
    bias = float(np.mean(pred - obs))
    rmse = float(np.sqrt(np.mean((pred - obs) ** 2)))
    r = float(np.corrcoef(obs, pred)[0, 1]) if n > 1 else np.nan
    denom = np.sum((np.abs(pred - np.mean(obs)) + np.abs(obs - np.mean(obs))) ** 2)
    ioa = 1 - np.sum((pred - obs) ** 2) / denom if denom > 0 else np.nan
    slope = float(np.polyfit(obs, pred, 1)[0]) if n > 1 else np.nan
    return pd.Series({"N": n, "Bias": bias, "RMSE": rmse, "r": r, "Slope": slope, "IOA": ioa})
