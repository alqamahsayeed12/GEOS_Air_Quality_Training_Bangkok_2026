# Participant Guide

## Before the Training

1. Create or confirm your Google account.
2. Register for an OpenAQ API key for the live exercise. The bundled recovery
   path remains available without a key.
3. Open Module 0 from the repository README.
4. Save a copy in Google Drive and run all cells.
5. Confirm that the final checklist reports no missing assets.

## During Each Module

1. Open the module from the README, not from a previously downloaded copy.
2. Save a personal Drive copy.
3. Run cells in order unless the instructor identifies an exercise cell.
4. Edit only the clearly labeled configuration or TODO blocks.
5. Keep timestamps in UTC after conversion and retain units in output labels.
6. Download figures and tables you want to keep before ending the runtime.

Every Module 1 run prints `GEOS source` and `OpenAQ source`. Include those lines
when recording results or asking for help.

## Asking for Help

Share the module number, section heading, cell output, and full error text. Never
share an OpenAQ key. Use the repository issue template when the problem remains
after the training session.
