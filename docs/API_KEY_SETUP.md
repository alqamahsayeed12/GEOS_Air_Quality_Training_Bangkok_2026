# OpenAQ API Key Setup

1. Open [OpenAQ registration](https://explore.openaq.org/register).
2. Create an account and verify the email address.
3. Sign in and create or view the personal API key.
4. In Module 1, run the key cell and paste the key into the hidden prompt.
5. Press Enter. The key remains in runtime memory for that session.

Do not place the key in a Python string, notebook markdown, environment file
tracked by Git, screenshot, issue, or chat. If a key is exposed, revoke it in
OpenAQ and generate a replacement.
