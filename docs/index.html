Participant readiness

Before you begin

The course runs in Google Colab. A local Python installation, specialist computer, or paid account is not required.

01
Laptop and reliable internet

Use a current version of Chrome, Firefox, Safari, or Edge. The network must allow access to Google Colab, Google Drive, GitHub, NASA data services, and OpenAQ.

02
Google account

Required to connect to a hosted Colab runtime and save a personal notebook copy in Google Drive.

03
Module 0 completed

Open the setup notebook, save a Drive copy, run all cells, and confirm that the repository, course assets, and scientific packages pass verification.

04
OpenAQ API key (recommended)

The live Module 1 observation exercise uses a personal key. View secure setup instructions. Recovery data are available if the service or key is unavailable.
